# Skill (landing repo)

This repo holds only the landing page and index for **Skill**, a set of free crypto helpers. It contains no code, just `README.md`.

| Product | Status (per README) | Source |
|---|---|---|
| Telegram bot [@Simple1990bot](https://t.me/Simple1990bot) | Live, v0.1.0 | [cryptospeed-bot](https://github.com/fitzyracing1/cryptospeed-bot) |
| Microsoft Teams bot | Planned | [skill-teams-bot](https://github.com/fitzyracing1/skill-teams-bot) |

To try it, open the Telegram bot and ask in plain English, for example "price of sol and doge". To run your own copy, see the [cryptospeed-bot docs](https://github.com/fitzyracing1/cryptospeed-bot/tree/main/docs).
