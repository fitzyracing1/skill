## Try it

Open [@Simple1990bot](https://t.me/Simple1990bot) and ask in plain English:

- “is it a good time to send btc?”
- “price of sol and doge”
- “tell me when eth gas under 1”
- paste a tx ID for confirmations
- `watch my wallet <your address>` for incoming funds

Never asks for keys. Never holds funds.
